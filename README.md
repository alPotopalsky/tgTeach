# MathBot

Простий Telegram-бот для тренування арифметики. Він генерує приклади на
додавання, віднімання та множення, підтримує безлімітні спроби й відповідає
великими емодзі. Складність зростає поступово: бот починає з трьох
кнопок-відповідей і збільшує їх кількість до шести. Після неправильної
відповіді емодзі з’являється в тому самому повідомленні, тому приклад
залишається на екрані. Серед математичних завдань поступово з’являються прості
англійські слова з вибором українського перекладу. Усі повідомлення сформульовані
нейтрально, без звертань за статтю.

Математика й англійська мають по 10 незалежних рівнів. Новий користувач
починає з рівня 5, після чого бот підвищує або знижує складність за останніми
відповідями. Та сама структура підтримує додавання нових предметів без нових
колонок у таблиці користувачів.

Перші 5 правильних відповідей із кожного предмета калібрують персональний темп.
Після калібрування бот може показати персональну бонусну ціль від 5 до 15 секунд.
Бонус `⚡🌟` нараховується лише за правильну відповідь із першої спроби.
Фактичний час не показується, але повністю записується для аналітики. Відповіді
до 15 секунд вважаються нормальними, від 15 до 20 — повільними, а понад
20 секунд — підозріло довгими й не прискорюють прогрес.

## Запуск

Потрібен Python 3.10 або новіший.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item token.example.txt token.txt
```

Замініть текст у `token.txt` на токен свого Telegram-бота, а потім запустіть:

```powershell
python mathbot.py
```

Замість `token.txt` можна задати змінну середовища `BOT_TOKEN`.

## Використання

Відкрийте чат із ботом і надішліть команду `/start`. Команда `/skip` показує
відповідь і переходить до іншого прикладу.

`DATABASE_URL` вказує на основну PostgreSQL із користувачами та рівнями.
`LOG_DATABASE_URL` вказує на окрему PostgreSQL із детальним журналом відповідей:
часом у мілісекундах, правильною відповіддю, ознакою першої спроби, класом
швидкості та бонусом. Автоматичне очищення журналу поки вимкнене; індекс за
датою вже підготовлений для майбутньої політики зберігання.

Якщо `LOG_DATABASE_URL` ще не заданий, журнал тимчасово створюється в
`DATABASE_URL`. Без `DATABASE_URL` локальний режим продовжує працювати, але
прогрес зберігається лише в пам’яті.

## Render

Репозиторій містить `render.yaml` для безплатного Render Web Service.

1. У Render Dashboard виберіть **New → Blueprint**.
2. Підключіть цей GitHub-репозиторій.
3. Під час створення сервісу задайте секретні змінні `BOT_TOKEN`,
   `DATABASE_URL` і `LOG_DATABASE_URL`.
4. Застосуйте Blueprint і дочекайтеся завершення deploy.

На Render бот автоматично використовує webhook. Під час локального запуску без
`RENDER_EXTERNAL_URL` він працює через polling.

Безплатний сервіс може засинати після періоду бездіяльності, тому перша відповідь
після паузи іноді надходить із затримкою.
