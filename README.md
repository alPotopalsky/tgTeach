# MathBot

Простий Telegram-бот для тренування арифметики. Він генерує приклади на
додавання, віднімання та множення, підтримує безлімітні спроби й відповідає
великими емодзі. Складність зростає поступово: бот починає з трьох
кнопок-відповідей і збільшує їх кількість до шести. Після неправильної
відповіді емодзі з’являється в тому самому повідомленні, тому приклад
залишається на екрані. Серед математичних завдань поступово з’являються прості
англійські слова з вибором українського перекладу. Усі повідомлення сформульовані
нейтрально, без звертань за статтю.

Прогрес зберігається окремо для 10 рівнів математики та 10 рівнів англійської.
Після переходу на наступний рівень бот більше не повертає прості завдання або
слова з попередніх рівнів.

## Запуск

Потрібен Python 3.10 або новіший.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item token.example.txt token.txt
```

Замініть текст у `token.txt` на токен свого Telegram-бота, а потім запустіть:

```powershell
python mathbot.py
```

Замість `token.txt` можна задати змінну середовища `BOT_TOKEN`.

## Використання

Відкрийте чат із ботом і надішліть команду `/start`. Команда `/skip` показує
відповідь і переходить до іншого прикладу.

Якщо задано `DATABASE_URL`, бот автоматично створює таблиці PostgreSQL,
зберігає кожну відповідь, час відповіді в мілісекундах і відновлює прогрес
користувача після перезапуску. Без бази даних локальний режим продовжує
працювати, але прогрес зберігається лише в пам’яті.

## Render

Репозиторій містить `render.yaml` для безплатного Render Web Service.

1. У Render Dashboard виберіть **New → Blueprint**.
2. Підключіть цей GitHub-репозиторій.
3. Під час створення сервісу задайте секретну змінну `BOT_TOKEN`.
4. Застосуйте Blueprint і дочекайтеся завершення deploy.

На Render бот автоматично використовує webhook. Під час локального запуску без
`RENDER_EXTERNAL_URL` він працює через polling.

Безплатний сервіс може засинати після періоду бездіяльності, тому перша відповідь
після паузи іноді надходить із затримкою.
